<h1 align="center">PS4 FTP Manager</h1>
<p align="center">
  A lightweight web interface for managing files on your PlayStation 4 via FTP.<br>
  Upload, browse, and organize files with ease.
</p>

---

## Requirements

Before you start, make sure you have:

- A **jailbroken PS4**
- **GoldHEN** installed and running
- In **GoldHEN Server Settings**:
  - Enable FTP Server
- Your PS4 connected to the same network as your PC

## Quick Start (Windows)

### 1. Download Release
- Go to the **Releases** page and download the latest `ps4-ftp-manager.zip` file.

### 2. Extract the ZIP
- Unzip the downloaded file to a folder of your choice.

### 3. Run the Server
- Double-click `run.bat`. This will:
  - Install any missing Node.js packages automatically.
  - Start the web server.
  - Open your browser at [http://localhost:3000](http://localhost:3000).

### 4. Connect to Your PS4
- Enter your PS4’s **IP address** and **FTP port** (default: `2121`).
- Click **Connect**.
- You can now browse, upload, and manage files easily.

### 5. Stop the Server
- Press `Ctrl + C` in the command window that opened with `run.bat`.
